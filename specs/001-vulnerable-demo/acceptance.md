# Acceptance Criteria

- [ ] App starts on loopback and health returns 200.
- [ ] Task list/read/create and summary work with synthetic SQLite data.
- [ ] Tests are deterministic; seed script is repeatable.
- [ ] Exactly eight intentional findings: 3 high, 3 medium, 2 low.
- [ ] Every defect maps to one catalog ID and one SARIF result.
- [ ] No real secrets, external calls, or undocumented vulnerabilities.
- [ ] README prominently says “intentionally vulnerable — local lab only”.
- [ ] SARIF is valid JSON, version 2.1.0, with rule IDs SFV-001–SFV-008 and locations.
- [ ] Import the fixture through the documented SecureFix AI UI/API and record actual behavior.
- [ ] Create a plan and proposal without applying or executing it.
- [ ] Distinguish synthetic catalog entries from actual scanner detections.
